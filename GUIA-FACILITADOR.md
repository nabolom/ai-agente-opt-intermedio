# Guía del facilitador

## Encuadre hablado

> “No van a simular un caso ajeno. Abrirán el PDF que ya revisaron y Cowork los llevará por lecciones. Primero decidirán si su problema necesita IA, una regla IF, un sistema híbrido o todavía no debe automatizarse. Solo después construirán harness, memoria, Skill y pruebas. Terminar con un bloqueo explícito también cuenta como avance.”

## Lanzamiento

Comparte el enlace del template y proyecta `README.md`. Pide que descarguen el ZIP, coloquen su PDF en `00-INPUT/`, abran la carpeta como Project, peguen `INSTRUCCIONES-PROJECT.md`, instalen el Skill y escriban:

```text
Inicia mi ruta AI Agent Opt.
```

## Tiempo sugerido

| Minuto | Checkpoint | Intervención del facilitador |
|---:|---|---|
| 0–7 | Repo descargado, PDF colocado, Project abierto | Resolver solo acceso y ubicación de carpeta. |
| 7–17 | Lección 1 completada | Verificar que separan hechos de inferencias. |
| 17–27 | Diagnóstico | Preguntar por causa raíz y expectativa. |
| 27–35 | Decisión IA/IF | Pedir evidencia; evitar que todos elijan IA. |
| 35–42 | Harness y memoria en borrador | Revisar permisos, fuente de verdad y gate. |
| 42–50 | Skill/pruebas o bloqueo documentado | Celebrar PASS o bloqueo explícito, no cantidad de archivos. |

## Señales de intervención

| Señal | Respuesta |
|---|---|
| Cowork genera todo sin preguntar | Detener y recordar el ciclo lección → preguntas → borrador → confirmación. |
| El alumno no tiene PDF | Usar el diagnóstico oral y documentar `BLOQUEADO: falta input`; no inventar un caso. |
| Quiere conectar todas sus apps | Volver a carpeta + PDF; exigir la necesidad antes del conector. |
| Elige IA porque “es más potente” | Preguntar si reglas IF producirían el mismo output exacto. |
| No termina | Pedir solo `02_DECISION-IA-IF.md`; es mejor una decisión sólida que un agente decorativo. |

## Debrief

Cada persona completa: “Mi caso es ___ porque ___; el principal bloqueo es ___; la decisión que conservo es ___; el siguiente experimento es ___.”
