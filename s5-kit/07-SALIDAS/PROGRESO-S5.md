# Progreso S5 · Cierra el loop

El coach actualiza este archivo solo después de mostrar evidencia y recibir confirmación.

| Fase | Estado | Evidencia |
|---:|---|---|
| 0 · Precheck y ruta | pendiente | Ruta verde, recuperación o demo |
| 1 · Configuración guiada | pendiente | `config-revision.md` |
| 2 · Supervisión | pendiente | `supervision-AAAA-MM-DD.md` |
| 3 · Teach-back | pendiente | Explicación del semáforo con evidencia |
| 4 · Auditoría | opcional | `auditoria-AAAA-MM-DD.md` o `omitida` |
| 5 · Cierre | pendiente | `cierre-s5.md` |

## Ruta

- Ruta asignada: `[verde / recuperación / demo]`
- Proceso revisado: `[propio / demo de embarques]`
- Faltante recuperado: `[ninguno / evidencia exacta / no aplica]`

## Regla de salida

S5 se completa con las fases 0, 1, 2, 3 y 5. La fase 4 puede quedar marcada como `omitida` sin bloquear el cierre.
