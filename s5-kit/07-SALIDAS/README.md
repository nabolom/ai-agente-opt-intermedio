# Salidas S5

El coach usa las plantillas y guarda aquí únicamente artefactos revisables:

| Plantilla | Archivo que obtienes | Valor |
|---|---|---|
| [`PLANTILLA-mapa-inicial.md`](PLANTILLA-mapa-inicial.md) | `mapa-inicial-s1-s5.md` | Hace visible el avance, los huecos y la ruta antes de supervisar |
| [`PLANTILLA-config-revision.md`](PLANTILLA-config-revision.md) | `config-revision.md` | Define qué significa que el output sirva |
| [`PLANTILLA-supervision.md`](PLANTILLA-supervision.md) | `supervision-AAAA-MM-DD.md` | Demuestra si corrió, si sirvió y qué evidencia existe |
| [`PLANTILLA-cierre-s5.md`](PLANTILLA-cierre-s5.md) | `cierre-s5.md` | Convierte el hallazgo en acción, responsable y fecha |

El mapa es evidencia obligatoria de entrada; los otros tres archivos son los entregables de cierre. Como extensión, el coach puede crear `auditoria-AAAA-MM-DD.md`. [`PROGRESO-S5.md`](PROGRESO-S5.md) permite reanudar sin repetir fases.

## Cuando termines

Comprueba la definición de terminado en [`../OUTCOMES-Y-TIEMPOS.md`](../OUTCOMES-Y-TIEMPOS.md). Deben existir el mapa de entrada y los tres entregables de cierre; además, debes poder defender la ruta y el semáforo con evidencia.

No coloques aquí archivos que deba procesar tu automatización. Esta carpeta es solo para reportes de S5.
