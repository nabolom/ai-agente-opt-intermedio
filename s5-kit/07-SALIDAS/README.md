# Salidas S5

El coach guarda aquí únicamente artefactos revisables:

- `config-revision.md`: configuración confirmada.
- `supervision-AAAA-MM-DD.md`: reporte obligatorio de una corrida.
- `auditoria-AAAA-MM-DD.md`: segundo nivel, si se realiza.
- `cierre-s5.md`: semáforo, siguiente paso, responsable y fecha.
- `PROGRESO-S5.md`: avance reanudable.

No coloques aquí archivos que deba procesar tu automatización. Esta carpeta es solo para reportes de S5.
