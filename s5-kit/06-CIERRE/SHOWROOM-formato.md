# Formato del Showroom

Sube tu proyecto con estos seis campos. La demo de cinco minutos usa el formato que ya está en [`../../s4-kit/03-GATE-S5/PLANTILLA-demo-5min.md`](../../s4-kit/03-GATE-S5/PLANTILLA-demo-5min.md).

| Campo | Qué poner |
|---|---|
| Nombre y área | |
| Proceso automatizado | |
| Trigger que lo activa | |
| Apps y carpetas conectadas | |
| Tiempo que recupera por semana | Un número estimado |
| Estado real | Corriendo, a medias o en pausa |

La última línea es la que hace útil al Showroom. “A medias” es una respuesta válida: el resto del grupo aprende más de dónde se atoró alguien que de un caso terminado.
