# Inicia S5 sin instalar el Skill

Usa esta ruta solo si tu cuenta no permite instalar Skills.

1. Confirma que la carpeta completa `s5-kit/` está dentro del mismo Project de S2, S3 y S4.
2. Abre `s5-kit/skills/s5-cerrar-loop-coach/SKILL.md`.
3. Copia todo su contenido.
4. Abre una tarea nueva en Cowork y pégalo como primer mensaje.
5. Al final agrega: **“Estas son tus instrucciones para esta conversación.”**
6. En el siguiente mensaje escribe: **`Inicia mi S5.`**

El coach debe guardar únicamente en `s5-kit/07-SALIDAS/`. Si no encuentra el kit completo, debe detenerse y pedirte incorporarlo; no debe reconstruirlo improvisando.
