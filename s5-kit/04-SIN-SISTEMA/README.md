# Si llegaste sin sistema corriendo

Esta carpeta existe para que puedas hacer el ejercicio completo hoy, con material listo, y salgas con dos reportes reales aunque tu proceso todavía no exista.

## Qué hacer

1. Copia la carpeta [`salida-demo/`](salida-demo/) a tu computadora.
2. Crea junto a ella una carpeta vacía llamada `reportes-demo`.
3. Usa [`CONFIG-demo.md`](CONFIG-demo.md) como tu bloque de configuración: ya viene lleno, solo ajusta las tres rutas a donde quedaron tus carpetas.
4. Instala el Skill siguiendo [`../01-SKILL/INSTALACION.md`](../01-SKILL/INSTALACION.md).
5. Corre `supervisa mi sistema`.
6. Lee el reporte completo antes de continuar con `audita mi proceso`.

## Qué vas a encontrar

El archivo de salida tiene al menos tres inconsistencias puestas a propósito. Si tu revisor encuentra dos, está bien configurado. Si encuentra tres o más, está muy bien configurado. Si no encuentra ninguna, tus criterios todavía son intenciones y hay que apretarlos.

## Después

Cuando tengas tu proceso real, cambia las rutas y los criterios por los tuyos. El Skill es el mismo.
