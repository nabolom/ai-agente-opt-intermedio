# Guía del facilitador · S5

Grupo: 6 participantes, todos en Cowork.

## Objetivo observable

Cada persona sale con una supervisión basada en evidencia y un siguiente paso con fecha. **La auditoría completa no es requisito para completar la sesión.**

## Antes de la sesión

1. Pide como prework que todos descarguen `dist/s5-kit.zip`, copien `s5-kit/` dentro de su Project e instalen `s5-kit/dist/s5-cerrar-loop-coach.zip`. Si se hace durante la sesión, reserva 10–15 minutos adicionales.
2. Proyecta una sola frase: **`Inicia mi S5.`**
3. Ten abierta la ruta demo de `s5-kit/04-SIN-SISTEMA/`.
4. Pide a quienes tengan sistema que ubiquen el último output real; no hace falta que sepan copiar su ruta.
5. Recuerda: si alguien no tiene output, va a demo. No intentes reparar S4 durante esta sesión.

## Elige una modalidad

### Modalidad A · 45 minutos · instalación como prework

| Min | Bloque | Resultado |
|---:|---|---|
| 0–5 | Apertura: correr ≠ funcionar | Entienden el propósito del loop |
| 5–10 | Precheck | Cada persona tiene una ruta |
| 10–17 | Criterios verificables | Configuración confirmada |
| 17–32 | Supervisión con el coach | `supervision-AAAA-MM-DD.md` |
| 32–38 | Teach-back en parejas | Explican color y evidencia |
| 38–44 | Siguiente paso | Acción, responsable y fecha |
| 44–45 | Cierre | Frase de compromiso |

### Modalidad B · 60 minutos · instalación durante la sesión

| Min | Bloque | Resultado |
|---:|---|---|
| 0–12 | Descargar, copiar e instalar | Coach activo en el Project |
| 12–17 | Apertura | Entienden el propósito del loop |
| 17–22 | Precheck | Cada persona tiene una ruta |
| 22–30 | Criterios verificables | Configuración confirmada |
| 30–47 | Supervisión con el coach | `supervision-AAAA-MM-DD.md` |
| 47–53 | Teach-back en parejas | Explican color y evidencia |
| 53–59 | Siguiente paso | Acción, responsable y fecha |
| 59–60 | Cierre | Frase de compromiso |

En ambas modalidades, la auditoría se omite durante el recorrido mínimo. Quien termine antes puede iniciarla; para hacerla con todo el grupo agrega **15 minutos**.

## Qué decir al abrir

> “Hoy no vamos a construir otra cosa. Vamos a comprobar si lo que construimos corre, si sirve y si se detiene donde prometimos. Si no tienes sistema, harás el mismo diagnóstico con una demo completa. Nadie se queda atrás.”

## Cuándo intervenir

Intervén si alguien:

- lleva más de tres minutos buscando una ruta: pídele que describa o señale la carpeta; el coach debe proponer la referencia;
- intenta rehacer S4: envíalo a recuperación mínima o demo;
- escribe criterios como “que esté bien”: usa la prueba de las dos personas;
- quiere reparar el proceso durante la supervisión: recuérdale que hoy diagnostica y prioriza;
- lleva más de 50 minutos sin reporte: omite auditoría y cierra el mínimo.

## Señales de éxito

Antes del cierre, cada persona debe poder mostrar:

1. `config-revision.md`.
2. `supervision-AAAA-MM-DD.md`.
3. `cierre-s5.md`.
4. Una frase oral: “Mi semáforo es ___ porque encontré ___; antes del viernes haré ___.”

## Plan B

Si falla la instalación para más de una persona, todos usan [`INICIAR-S5-SIN-SKILL.md`](INICIAR-S5-SIN-SKILL.md). Si el problema es el material propio, todos pueden terminar con la demo; no uses tiempo grupal para reparar sistemas individuales.
