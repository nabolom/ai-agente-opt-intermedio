# Sesión 1 · Documenta tu automatización

## Outcome

Al terminar tendrás un **PDF de mapa de proceso** que usarás como input en S2. El PDF no decide todavía si necesitas IA ni constituye una especificación técnica; documenta tu hipótesis actual del proceso.

## Actividad · 30 minutos

1. Abre [Cloud para Automatización](https://my-automation.bolt.host/).
2. Escribe tu nombre y pulsa **Comenzar actividad**.
3. Responde los siete pasos con información que puedas usar durante el curso.
4. Revisa tus respuestas antes de generar el documento.
5. Pulsa **Descargar PDF**.
6. En el diálogo del navegador, elige **Guardar como PDF**.
7. Nombra el archivo `mi-automatizacion.pdf` y consérvalo para S2.

## Qué contiene el PDF

| Sección | Pregunta que documenta |
|---|---|
| Nombre del proceso | ¿Qué proceso quieres entender y mejorar? |
| Información de entrada | ¿Qué necesita el proceso para arrancar y de dónde viene? |
| Herramientas | ¿Qué apps, archivos o carpetas toca hoy? |
| Output y destinatarios | ¿Qué produce y quién lo recibe? |
| Intervención manual | ¿Dónde participas y qué ocurriría si no estuvieras? |
| Juicio humano | ¿Qué depende de contexto no escrito o criterio tácito? |
| Versión mínima | ¿Qué subproceso podría automatizarse primero? |

## Criterio de terminado

El archivo abre correctamente, contiene las siete respuestas y evita secretos, datos personales innecesarios o información que no puedas compartir con Cowork.

> En S2, Cowork cuestionará este mapa, buscará faltantes y decidirá si el MVP realmente necesita IA, una regla IF, un sistema híbrido o todavía no debe automatizarse.
