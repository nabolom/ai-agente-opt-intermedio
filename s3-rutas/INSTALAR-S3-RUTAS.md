# Instalar S3 Rutas sin perder tu trabajo anterior

Esta actividad se agrega a la misma carpeta que usaste en S2. **No reemplaza** tus outputs, memoria, instrucciones ni archivos aprobados.

## Pasos

1. Descarga [`s3-rutas-kit.zip`](dist/s3-rutas-kit.zip).
2. Descomprime el archivo.
3. Copia la carpeta completa `s3-rutas/` dentro de la carpeta que ya utilizaste en S2.
4. Si tu equipo pregunta si deseas reemplazar archivos, elige **no reemplazar**. La carpeta usa un nombre nuevo y no debería existir todavía.
5. Abre el mismo Project de Cowork para conservar el contexto aprobado de S2.
6. Abre [`INSTRUCCIONES-COWORK-S3.md`](INSTRUCCIONES-COWORK-S3.md), copia su bloque y **agrégalo al final** de las instrucciones actuales del Project. No reemplaces las instrucciones de S2.
7. Guarda el cambio, empieza una tarea nueva y escribe: `Inicia mi S3 Rutas.`
8. Verifica que Cowork localice tu decisión de S2 y lea [`03-SALIDAS/PROGRESO-S3.md`](03-SALIDAS/PROGRESO-S3.md).
9. Continúa desde [`EMPIEZA-S3-RUTAS.md`](EMPIEZA-S3-RUTAS.md).

## Qué se conserva

| Trabajo anterior | Qué ocurre |
|---|---|
| Tu PDF de entrada | Se conserva sin cambios. |
| `02_DECISION-IA-IF.md` | Se usa como punto de partida; no se reemplaza. |
| `04-SALIDAS/` | Se conserva sin cambios. |
| `PROGRESO.md` | Se conserva sin cambios. |
| Skills y memoria anteriores | Permanecen disponibles. |

## Qué se agrega

La carpeta nueva contiene la demo neutral de facturas, las cuatro rutas, dos Skills instalables, instrucciones aditivas para Cowork, un progreso exclusivo de S3 y las plantillas para guardar tu tabla, tus pruebas o tus reglas.

> **Comprobación rápida:** al escribir `Inicia mi S3 Rutas.`, Cowork debe confirmar que ve `s3-rutas/`, localizar tu `02_DECISION-IA-IF.md` de S2 y decirte cuál es la primera fase pendiente. Si hace las tres cosas, estás listo.
