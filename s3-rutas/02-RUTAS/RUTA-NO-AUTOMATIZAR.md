# Ruta No automatizar todavía

Ese veredicto es sobre el proceso completo. Casi siempre hay un paso que sí.

Hoy construyes dos cosas.

## 01 · Nombra el faltante con precisión

«Falta información» no sirve. Necesitas saber exactamente qué falta y quién lo tiene.

| Pregunta | Tu respuesta |
|---|---|
| ¿Qué tipo de faltante es: **dato**, **regla** o **permiso**? |  |
| ¿Qué es exactamente? |  |
| ¿Quién lo tiene o quién puede autorizarlo? |  |
| ¿Qué haría falta para conseguirlo? |  |
| ¿Cuánto tiempo tomaría, de verdad? |  |

### Los tres tipos

**Falta un dato.** La información no existe en ningún lado, o existe pero nadie la captura. Se resuelve capturándola, y eso empieza esta semana.

**Falta una regla.** El criterio vive en la cabeza de alguien y nadie lo escribió. Se resuelve con una conversación de treinta minutos con esa persona.

**Falta un permiso.** El acceso existe pero no lo tienes. Se resuelve pidiéndolo — y necesitas saber a quién.

## 02 · El paso más chico que sí puedes construir hoy

Vuelve a tu tabla de pasos. Casi seguro hay uno que no depende del faltante.

> El paso que sí puedo construir hoy: `[cuál]`
>
> Por qué no depende del faltante: `[razón]`
>
> Qué produce: `[output]`

Constrúyelo. Aunque sea el 20% del proceso, sales con algo corriendo.

## Lo que NO se vale hoy

Rediseñar el proceso completo esperando que el faltante aparezca. Si al final de la sesión tienes un diseño más bonito y nada corriendo, la sesión no sirvió.

## Tu entregable

1. El faltante nombrado, con dueño y plazo.
2. Un paso construido y probado.
